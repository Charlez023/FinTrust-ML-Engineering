# FinTrust ML Engineering — Dependencies

## Data Science

The MLE workflow depends on the Data Science track for the final features, selected model, model training and evaluation, trained model artifact, and expected model input and output formats.

## Data

The workflow depends on the FinTrust customer and transaction datasets. The data dictionary will help with understanding the fields, while the financial knowledge base is mainly relevant to the Generative AI track.

## Business Requirements

The prediction output should follow the wider FinTrust business requirements. The MLE track should not make business decisions that belong to the overall project.

## Other Project Tracks

The MLE component may need to connect with outputs from the Generative AI and other tracks depending on the final solution architecture.

## Deployment

Later stages may require model storage, a runtime environment, an API or service layer, dependency management, logging, monitoring, and versioning. These are not required to be fully implemented during Week 1.

## Integration

The MLE components should have clear connections between data, preprocessing, features, the model, and inference. This will make the system easier to integrate and maintain.
